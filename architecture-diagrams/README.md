## Notes
- SVG files are vector graphics: they stay sharp when zoomed and can be embedded in Markdown, slides, and documentation.
- Diagrams are conceptual reference architectures, not mandatory implementations. Real systems may add, remove, or reorder components based on requirements.
- Arrows show the primary conceptual flow; feedback loops and control boundaries should be discussed alongside each diagram.
